# 📡 Спецификация доменной модели датчиков и устройств (Domovoy.Domain)

Документ описывает классификацию, параметры и типы устройств умного дома платформы «Домовой».

---

## 🏗 Связь с доменной моделью C# (`Domovoy.Domain`)

В коде платформы сущности представлены следующими классами:
* **`Device`** — базовое устройство (содержит сетевой `DeviceId`, `ConnectionType`, `IPAddress`, `Port`, `IsOnline`, `LastActivity`, ссылку на `RoomId` и `UserId`).
* **`Sensor`** — датчик устройства (`SensorType`, `Unit`, `MinValue`, `MaxValue`, `CurrentValue`, `ReadingInterval`, `IsActive`).
* **`Actuator`** — исполнительное устройство (`ActuatorType`, `CurrentState`, `IsActive`).
* **`SensorReading`** — историческая запись телеметрии (`Value`, `Timestamp`).
* **`Scenario` / `ScenarioCondition` / `ScenarioAction`** — правила автоматизации, где условия привязаны к `Sensor`, а действия — к `Actuator`.

## 🏷 Классификация устройств (Device Types & Categories)

### 1. DeviceType (Тип устройства)

| Тип | Описание | Примеры |
| :--- | :--- | :--- |
| **Sensor** | **Датчик** — собирает физические параметры внешней среды и передает в систему | Датчик температуры, движения, открытия, влажности |
| **Actuator** | **Исполнительное устройство** — принимает команды управления и меняет физическое состояние | Умное реле, сервопривод крана, термоголовка, умная розетка |
| **Controller** | **Шлюз / Интерфейс** — координатор или устройство отображения | Сенсорный экран, пульт, хаб |

### 2. DeviceCategory (Категория применения)

| Категория | Описание | Примеры |
| :--- | :--- | :--- |
| **Security** | **Безопасность** — контроль периметра и несанкционированного доступа | Геркон двери/окна, датчик движения, сирена |
| **Climate** | **Климат и комфорт** — управление микроклиматом и средой | Датчик температуры/влажности, теплый пол, кондиционер |
| **Emergency** | **Предотвращение аварий** — отслеживание утечек и аварийных ситуаций | Датчик протечки, датчик дыма, газоанализатор, перекрывной кран |
| **Energy** | **Энергопотребление** — контроль расхода ресурсов | Счетчик электроэнергии, умная розетка с ваттметром |

### 3. DevicePowerSupplyType (Тип питания)

| Тип | Описание |
| :--- | :--- |
| **Battery** | Автономное батарейное питание (CR2032, CR123A, AA/AAA). Требует контроля уровня заряда |
| **AC** | Переменный ток 220В (постоянное сетевое питание) |
| **DCA** | Постоянный ток низкого напряжения (5В, 12В, 24В) через блок питания |
| **PoE** | Power over Ethernet (питание по витой паре) |
| **Solar** | Солнечная панель с буферным аккумулятором |

## 🎯 Типы сенсоров (`SensorType`) и физические параметры

| SensorType | Описание | Единицы измерения (`Unit`) | Диапазон по умолчанию |
| :--- | :--- | :--- | :--- |
| **TemperatureSensor** | Температура воздуха | °C, °F | -40 .. +85 °C |
| **HumiditySensor** | Относительная влажность | % | 0 .. 100 % |
| **MotionSensor** | Датчик движения (PIR / Microwave) | boolean (0 / 1) | 0 .. 1 |
| **PresenceSensor** | Датчик присутствия (mmWave) | boolean (0 / 1), m (дистанция) | 0 .. 1 |
| **DoorWindowSensor** | Открытие двери / окна (геркон) | boolean (0 / 1: Закрыто / Открыто) | 0 .. 1 |
| **LightSensor** | Освещенность | lux | 0 .. 100 000 lux |
| **FloodSensor** | Датчик протечки воды | boolean (0 / 1: Сухо / Затопление) | 0 .. 1 |
| **SmokeSensor** | Датчик задымления | ppm, boolean | 0 .. 1 |
| **GasLeakSensor** | Датчик утечки газа (CH4, CO) | ppm, % LEL | 0 .. 10 000 ppm |
| **EnergyMeter** | Измеритель мощности и энергии | W, kW·h, V, A | 0 .. 10 000 W |

## ⚙️ Типы актуаторов (`ActuatorType`) и команды

| ActuatorType | Назначение | Состояния (`CurrentState`) | Примеры команд |
| :--- | :--- | :--- | :--- |
| **Switch** | Включение/выключение нагрузки | `On`, `Off` | `turn_on`, `turn_off`, `toggle` |
| **Dimmer** | Плавное регулирование уровня (свет, обороты) | `0%` .. `100%` | `set_level`, `dim_up`, `dim_down` |
| **Valve** | Электропривод перекрытия воды/газа | `Open`, `Closed` | `open_valve`, `close_valve` |
| **Thermostat** | Термостатический регулятор отопления | `15.0°C` .. `30.0°C`, `Auto`, `Off` | `set_target_temperature`, `set_mode` |
| **Lock** | Электронный замок / защелка | `Locked`, `Unlocked` | `lock`, `unlock` |

## 📊 Параметры настройки и обработки телеметрии

* **`ReadingInterval` (Интервал опроса):** Частота генерации телеметрии устройством (в секундах).
* **`MinValue` / `MaxValue` (Диапазон валидации):** Граничные значения физической величины для отсеивания аномальных выбросов датчика.
* **`CurrentValue` (Текущее значение):** Кэшированное оперативное показание, обновляемое при получении `TelemetryReceivedEvent`.
* **`Hysteresis` (Гистерезис):** Разница порогов включения/выключения для предотвращения дребезга в Rules Engine (например, включение нагревателя при < 20°C, выключение при > 22°C).
